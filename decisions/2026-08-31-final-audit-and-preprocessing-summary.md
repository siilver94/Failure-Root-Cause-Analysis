# FRA 데이터 전처리 여정 — 최종 정리

최종 산출물: `fra_master_v3.csv` (13,482건, 58개 필드)
검증 완료일: 2026-08-31

## 원본에서 마스터까지, 무엇을 했는가

### 1. 모집단 범위 확정 (285개 컬럼 → 북미 전용)
- SFDC 원본은 Korea / North America / Global 3개 지역이 사실상 다른 스키마로 혼재
- 북미+글로벌만 남기고 컬럼 285개 → 43개로 선별 (완전결측/단일값/중복 컬럼 제거)

### 2. B/S(캠페인) 오염 제거
- 한국 클레임의 절반 이상이 실제 고장이 아닌 예방적 조치(캠페인, 정기서비스)였음을 발견
- `Kor_RequestTypeA__c`(A/S vs B/S vs PDI)로 구분, A/S만 고장으로 집계
- 이 문제 자체는 북미 데이터에는 없음(구조가 다름)

### 3. NA-Global 2단계 청구 구조 규명 (가장 중요한 발견)
- 북미는 "딜러→TYM-USA(NA)→본사(Global)"의 2단계 구조이며, 처리가 안 되면 Global로 재클레임됨
- 같은 고장 하나가 NA·Global 두 레코드로 중복 존재 (8,399~8,813건 규모)
- 연결키: Global의 `OriginalClaimNumber__c` = NA의 `Id`
- 담당자 확인: NA에서 처리 안 되면 Global로 재클레임 → **완전한 데이터는 Global 쪽**
- 처리: LEFT JOIN + COALESCE로 병합(v1의 UNION ALL 방식은 NA 전용 정보 소실 문제로 폐기)
- NA 1건에 Global 2건 이상 붙는 예외(22~25건)는 Status=Closed 우선으로 대표 1건 선택

### 4. 분자(고장 건수) 정의 확정
- `Status`(승인/거절)는 고장 유무와 무관 — Rejected 상당수가 실제 고장(보증만료 등으로 비용만 미지급)
- `ClaimType__c='In Stock'`은 판매 전 상태로 확인 → 제외
- `Damaged`/`Shortage`/`In House`도 물류·행정 사유로 제외
- 최종 분자 정의: `ClaimType__c`만 필터, `Status`는 필터링에 쓰지 않음

### 5. Parts/Causal/Labor 데이터 통합
- 신규 수신 데이터가 Case+Parts+Labor를 조인한 형태로 와서 클레임당 최대 156행까지 평탄화되어 있었음
- 담당자 확인: 정상 구조(Part×Labor 조합), 곱연산 버그 아님
- `CausalPart__c=True`가 분자(주원인) — 북미는 클레임당 정확히 1개(전수 검증, 예외 1건은 부품 대체 이력)
- 한국은 다름(126건이 True 2개 이상) — 북미 마스터 설계에 영향 없음, 한국 분석 시 재설계 필요
- Labor 라인의 22.1%가 0원/0시간 → 담당자 확인: 시스템 자동생성 빈 레코드, SUM 집계 시 무해

### 6. 컬럼명 충돌 해결
- 원본에 `Id`, `CreatedDate`, `ClaimId__c`가 Case/Labor 양쪽에 존재해 pandas가 `.1` 자동 부여
- 담당자가 `.labor` 접미사로 정리한 재출고본 수령, 검증 결과 내용 100% 동일 확인

## 알려진 한계 (분석 시 반드시 감안)

1. **분모 없음** — 기종별 생산·판매 대수 미확보. 고장률(빈도/모수) 계산 불가, 건수 비교만 가능
2. **귀책(협력사) 매핑 없음** — 부품번호는 있으나 공급 협력사 연결 안 됨. 구매본부 확인 필요(파킹)
3. **보증 만료일 없음** — 판매일자만 있고 만료일 계산 불가
4. **FailureDate 결측 5건** — 전부 실제 고장(그중 Front Axle 1건). 가동시간·시점 분석 시 자동 누락됨
5. **승인>청구 634건(4.7%)** — 승인률 지표 설계 시 100% 초과 가능성 있음
6. **IsSentHQ 불일치 2,667건** — SFDC 도입 과도기(2024~2025, 옥천/익산 별도 관리) 잔재, 추적 불가로 종결
7. **유상 수리 데이터 없음** — 북미·한국 모두 보증 종료 후 딜러 자체 처리, 시스템 미기록
8. **한국 데이터 별도 설계 필요** — 자유 텍스트 원인, B/S 오염, Causal 다중 구조 등 북미와 근본적으로 다름
