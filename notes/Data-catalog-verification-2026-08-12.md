# 데이터 카탈로그 검증 기록

작성일: 2026-08-12
대상: TYM_품질분석_데이터카탈로그_v2.xlsx, v3.xlsx (Copilot이 SharePoint/Teams 전수조사로 자동 생성)

## 왜 검증했는가

Copilot이 자동 생성한 문서를 검증 없이 분석 설계의 근거로 삼는 것은 위험하다고 판단.
자동생성 문서 특유의 리스크(환각, 파일 존재와 접근성 혼동, 날짜/버전 혼선 가능성)를 고려해,
이후 분석의 전제가 되는 핵심 주장만 선별하여 원본 파일과 직접 대조했다.

## 발견된 주의사항

1. **CauseCode 컬럼이 3개**(`CauseCode__c`, `CauseCode2__c`, `CauseCode3__c`)로 나뉘어 있음.
   카탈로그 초기 서술은 이를 단순화해서 언급한 부분이 있었음(v3에서 SFDC컬럼안내 시트로 개선됨).
   → 향후 카탈로그 참조 시, 숫자는 신뢰하되 서술이 실제 구조를 정확히 반영하는지는 재확인할 것.

2. **필드클레임 심각도 라벨(18%, 7,700건)의 분포가 8점/10점에 편중**되어 있고 1~3점은 전무함.
   → 무작위 표본이 아니라 "심각해 보이는 것 위주로 라벨링된" 편향된 부분집합일 가능성.
   분석 시 이 편향을 감안해야 함 (예: 이 18%로 전체 심각도 분포를 추정하면 왜곡됨).

## 결론

카탈로그(v2, v3 공통)의 핵심 수치는 신뢰할 수 있는 수준으로 판단. 이후 분석에서 카탈로그의
연결키·전처리규칙·컬럼 안내를 근거 자료로 사용 가능. 단, 프로젝트가 진행되며 카탈로그가 갱신될
때마다 핵심 수치는 위와 같은 방식으로 표본 검증하는 습관을 유지할 것.
