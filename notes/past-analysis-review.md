# 지난 클레임 분석 2건 부검 (Post-mortem)

작성일: 2026-08-10
대상: (1) 국내 클레임데이터 키워드 분석 (2024-10-25 중간보고), (2) 북미 T574SHUSM1 클레임 분석 (5차 보고)

## 1. 보고 경로와 결과

- 보고 경로: 팀장 → 소장 → 상품기획팀장 → (대표이사 보고 시도)
- 대표이사 보고는 대표이사 교체 시기와 맞물려 무산, 이후 프로젝트가 유야무야 종결됨
- 두 분석 모두 조직적 조치(설계변경, 공정개선, 검사기준 변경 등)로 이어지지 않음
- 품질본부는 두 분석 어디에도 관여하지 않음 (참고: 품질본부는 현재 AI 없이 사람이 수작업으로
  클레임 행 단위 분류를 진행 중)

## 2. 제거된 가설 / 남은 가설

분석에 참여한 의사결정자들의 권한과 동기를 확인한 결과:
- 팀장/소장 모두 데이터 분석의 중요성을 인지하고 있었음 (조직 전체로 보면 소수)
- 소장은 연구원에게 직접 설계변경을 요청할 수 있는 권한 구조가 존재함
- 회사 전반적으로 품질 이슈에 대한 민감도가 높은 상황이었음 (개선 동기 과잉이라 볼 수 있음)

→ "권한이 없었다", "동기가 없었다"는 가설은 기각.
→ 남는 가설: 분석 결과 자체가 행동으로 전환되지 않는 형태였다.
→ 대표이사 교체 타이밍은 불운이었으나, 통제 밖 요인이므로 이번 프로젝트의 개선 대상에서 제외.

## 3. 구조적 분석 (국내 보고서, 전체 18슬라이드)

| 구간 | 슬라이드 | 비중 |
|---|---|---|
| 문제 정의 | 2~4 | 3장 |
| 전처리 과정 설명 | 5~13 | 9장 |
| 분석 결과 | 14~15 | 2장 (14는 전처리 전후 비교) |
| 향후 계획 (미착수 항목 나열) | 16~18 | 3장 |

결과 슬라이드(15p)는 클레임 텍스트 단어 빈도 Top 40 (marginal distribution, 분모 = 전체 단어 토큰 수).
상위 단어(불량 12.6%, 발생 9.5%, 추정 8.3%, 파손 6.2%, 작동 4.1%)는 거의 모든 클레임 문장에 등장하는
서술어 성격이 강해 실질적으로는 불용어에 가까움. 조치를 특정할 수 있는 정보가 없음.

## 4. 북미 보고서 (T574SHUSM1, 5차, 27슬라이드)

국내 대비 진화한 지점:
- 분석 대상을 전사 → 특정 기종(T574SHUSM1)으로 좁힘 (범위 특정)
- 부품(Part), 사용시간(Operating Hours), 초기/비초기 여부까지 변수 결합
- 데이터 품질 문제(수집·매칭에 전체 작업시간의 70~80% 소요, 생산일자/판매일자 매칭 어려움)를
  6페이지에서 정직하게 문서화

한계:
- 표지의 보고 목적 체크박스가 "정보전달"로 체크됨 (의사결정/지시사항 아님) →
  설계 단계부터 실행 유도를 목표로 하지 않았음
- 8페이지 "Part별 고장 점유율"은 marginal (T574SHUSM1 207건 전체 기준, 부위로만 분해)
- 9페이지에서 사용시간대로 재분해(conditional 시도)한 것은 방향이 맞았으나,
  밸브(Valve) 사례의 경우 전체 5.3%(약 11~13건)를 다시 4~5개 시간 구간으로 쪼갠 것이라
  "0~200시간에 54% 집중"이라는 결과의 실제 근거는 n=13 수준 → 통계적 확신을 갖고
  "초기 불량 성향이 강하다"고 말하기엔 표본이 지나치게 작음

원본 데이터: 37,285건 전체 → causal 필터링 후 8,157건 → T574SHUSM1 한정 후 약 207건 (약 0.5%)

## 5. 다음 분석에 반영할 것

1. 첫 슬라이드/문서에 "이 분석의 목적은 정보전달인가, 의사결정 요청인가, 지시사항인가"를
   명시적으로 정하고 시작한다.
2. 전처리 과정은 부록으로 분리하고, 본문은 결론(무엇을 바꿔야 하는가) 중심으로 구성한다.
3. marginal 집계에서 멈추지 않고, 최소 1개 이상의 변수로 조건화(conditional)한 결과까지 간다.
4. 조건화하여 셀을 쪼갤 때마다 표본 크기(n)를 함께 명시하고, 통계적 유의성 검토 없이
   "패턴이 있다"고 단정하지 않는다.
5. 결론에는 반드시 귀책 주체(협력사 / 엔진사 / TYM 자체 설계·조립)를 특정한다.
