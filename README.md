# Failure Root-Cause Analysis (FRA)

TYM 중앙기술연구소 — 클레임 데이터 기반 트랙터 고장 원인 분석 프로젝트

## 목적

트랙터 클레임 데이터를 기반으로 고장 원인을 규명하여, 협력사 부품 / 외부 엔진사 / 자사 설계·조립 중
어디에 개선이 필요한지 실행 가능한(actionable) 결론을 도출한다.

## 문서 구조

- [`CLAUDE.md`](./CLAUDE.md) — 프로젝트 현재 상태, 도메인 배경, 핵심 방법론 원칙 (계속 갱신됨)
- [`decisions/`](./decisions) — 의사결정 기록 (ADR 스타일, 추가만 하고 과거 기록은 수정하지 않음)
- [`notes/`](./notes) — 분석 과정에서 나온 리뷰, 조사 자료

## 진행 상태

세부 진행 상황은 사내 업무일지 및 Notion에서 관리하며, 이 repo는 코드와 의사결정의
재현 가능한 기록 저장소로 사용한다.

## 데이터 취급

클레임 데이터 원본은 이 repo에 포함하지 않는다 (`.gitignore` 참고). 코드에서 참조하는 데이터는
로컬 경로 또는 별도 보안 스토리지를 사용한다.
