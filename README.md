# Failure Root-Cause Analysis (FRA) — 고장 원인 분석

TYM 중앙기술연구소, 트랙터 워런티 클레임 데이터 기반 고장 원인 분석 프로젝트.
목표: 협력사 / 엔진사 / 자사(TYM) 중 누가 무엇을 해야 하는지 실행 가능한 결론 도출.

**1차 대상: 전차축(Front Axle), 북미**

---

## 지금 상태 (2026-09-07 기준)

- ✅ SFDC 클레임 원본(57,901건) → 검증된 마스터(13,482건) 구축 완료
- ✅ 분자(고장) 정의 4단계 재검증 → Front Axle **1,858건** 확정 (Branson 단종 브랜드 제외 후)
- ✅ 원인 부품 카테고리 분류, 공식 플랫폼 그룹 매핑, 부품-공급사 매칭(부분) 완료
- 🔄 플랫폼별 부품 프로파일 차이의 통계적 유의성 검정 — **Claude Code에서 진행 중**
- ⚠️ 원본 그대로 집계하면 **Front Axle이 최대 90% 이상 과대계상**됨 (아래 3번 참고)

## 왜 원본을 그대로 쓰면 안 되는가

| 원인 | 내용 |
|---|---|
| 중복 구조 | 북미 클레임의 65%가 NA→본사(Global)로 재클레임되며 동일 건이 두 번 기록됨 |
| 지역 오분류 | `RecordType.Name='Global'`의 일부는 북미가 아니라 비북미 해외 파트너사 |
| 비고장 혼입 | 선제적 리콜/점검, 부품 누락, 운송파손 등이 고장 클레임과 섞여 있음 |
| 필드명 오독 | `ClaimType__c='Damaged'`, `'In House'`는 이름과 달리 대다수 실제 고장이었음(실측 필요) |

상세 근거와 검증 수치는 `notes/master-dataset-specification.md` 참고.

## 핵심 발견 (2026-09-07 기준)

- **Front Axle 고장의 약 90%가 누유(Leakage) 또는 파손(Breakage)** — 3개 독립 소스
  (SFDC 데이터, 상품기획 VOC, Reddit/TractorByNet 커뮤니티)에서 일관되게 확인됨
- **원인 부품은 씰(Seal)·베어링(Bearing) 계열이 다수** (부품 정보가 있는 건 중 약 59%)
- **플랫폼(기종군)에 따라 부품 프로파일이 다름**
  - 소형기 계열(Group/Model 4, 5): 씰·베어링 위주, 기어 문제 거의 없음
  - 중대형기 계열(Group/Model 14): 기어 문제 비중이 높음
  - 핵심 대상(Group/Model 10, T494/T574): 여러 부품에 고르게 분산
  - → 통계적 유의성 검정 진행 중

## 알려진 한계

1. 고장률 분모(생산·판매 대수) 미확보 — 건수 비교만 가능
2. 부품-공급사 매칭률 67.6%에 그침 — 미매칭 부품 소수(6개)에 집중, 사유 확인 중
3. 보증 만료일 컬럼 없음 / 유상 수리 데이터 없음 (마모성 고장 과소관측 가능)
4. 부품정보 없는 건(전체의 약 29%)이 파손(Breakage) 유형에 편중 — 부품 단위 결론의 한계로 명시 필요

전체 한계 목록은 `CLAUDE.md` 참고.

## 데이터 취급 원칙

- 클레임 원본, 사내 엑셀 파일은 어떤 형태로도 커밋하지 않는다 (`.gitignore` 참고)
- 모든 필터 조건은 적용 전 `DescriptionOfFailure__c` 등 텍스트로 샘플 대조 후 확정한다
  (컬럼명·값 이름만 보고 판단해 여러 차례 오류가 발생했던 이력 있음)
- 통계 검정 결과는 항상 표본 크기(n)와 함께 보고한다
